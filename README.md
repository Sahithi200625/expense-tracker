# 🧮 Calculator

A simple and user-friendly **Calculator Web Application** built using **HTML, CSS, and JavaScript**. It performs basic arithmetic operations with a clean and responsive interface.

## 🚀 Features

* Addition (+)
* Subtraction (-)
* Multiplication (×)
* Division (÷)
* Clear button
* Delete/Backspace functionality
* Decimal number support
* Responsive and simple user interface

## 🛠️ Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling and layout
* **JavaScript** – Calculator logic and operations

## 📂 Project Structure

```text
Calculator/
│
├── index.html
├── style.css
└── script.js
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Start using the calculator.

## 💡 How It Works

The calculator accepts numbers and mathematical operators from the user. JavaScript processes the input and displays the calculated result on the screen.

## 🎯 Purpose

This project was created to practice **HTML, CSS, and JavaScript** fundamentals and to understand how user interactions and calculations can be implemented in a web application.
